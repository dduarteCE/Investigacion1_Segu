# Demo o ejemplo práctico — Tema 3

**Tema:** Criptografía post-cuántica.

Esta carpeta contiene los materiales de la demo para la presentación. La demo
debe ocupar aproximadamente 5–8 minutos dentro de una exposición mínima de 15
minutos y estar conectada explícitamente con los trabajos de la literatura.

Reglas mínimas:

- Ejecutar solo en una VM, contenedor, laboratorio del curso o nube educativa
  bajo control del grupo.
- No atacar terceros ni escanear redes ajenas.
- No usar datos personales reales.
- Preparar una ruta alternativa (video o capturas) por si falla la ejecución en
  vivo.
- Guardar evidencia reproducible y anotar versiones, comandos no destructivos,
  configuración y resultados esperados.

Subcarpetas:

- `codigo/`: scripts o configuración de la demo.
- `datos/`: datos sintéticos, propios o consentidos.
- `evidencia/`: capturas, video, logs sanitizados.
- `resultados/`: salidas y observaciones que se citarán en el informe o en IN3–IN4.
